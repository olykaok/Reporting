# Project Brief: Jira Reporting System

## Overview
This project is a Jira reporting system that extracts data from Jira using JQL filters and generates detailed reports in JSON and CSV formats. The system processes work estimation and time tracking data for project management and reporting purposes.

## Core Objectives
1. Extract Jira issue data using configurable JQL filters
2. Process time estimation and tracking information
3. Generate structured reports in JSON format for data storage
4. Create detailed CSV reports for analysis and reporting
5. Organize output files in appropriate directory structure

## Key Requirements
- Support for Jira REST API integration
- Configurable JQL filtering
- Time estimation processing with different rounding options
- Multiple report formats (JSON, CSV)
- Proper file organization (input/output separation)
- Error handling and logging capabilities

## Success Criteria
- Reliable data extraction from Jira
- Accurate time calculations and conversions
- Proper file placement in designated directories
- Clear console output and error reporting
- Maintainable and extensible codebase
